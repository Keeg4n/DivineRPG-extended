## Antidote: jungle set

- Full Divine jungle set: poison has no effect at all, and the other bad effects are not removed but pass twice as fast. This also applies to foreign effects that milk does not remove, such as Thaumcraft warp (sun scorn, unnatural hunger, blurred vision, etc.). Good effects are untouched. The tooltip of the set pieces has a line about the antidote.
- The Wanderer perk with the jungle set as donor is now called "Antidote" and gives the same thing.
- Before, the jungle set cancelled any magic damage (both the harming potion and foreign magic). Now only the poison tick.
- The speed is configurable (balance, jungleDebuffSpeed, default 2).
