## Ender weapons against Ender mobs

- Only an Ender Bow arrow hits Endermen, Ender Watchers and Ender Spiders from Divine: while it is in flight, the target cannot teleport away. They still dodge regular arrows.
- Hitting an Ender mob with an Ender sword of any color prevents it from teleporting for 3 seconds.
- Disabled the DivineRPG update check when a player joins: without a network response the server could hang.
