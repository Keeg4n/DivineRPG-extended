## Эндер-оружие против эндер-мобов

- По эндермену, эндер-наблюдателю и эндер-пауку Divine попадает только стрела эндер-лука: пока она летит, цель не может уйти телепортом. От обычных стрел они по-прежнему уворачиваются.
- Удар эндер-мечом любого цвета на 3 секунды запрещает эндер-мобу телепортироваться.
- Отключена проверка обновлений DivineRPG при входе игрока: без ответа сети сервер мог зависнуть.
