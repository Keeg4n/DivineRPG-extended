## Fixed

- Loading ranged weapons (sneak + right-click): arrows and other ammo with an empty tag, which Crucible servers and some mods leave, are no longer considered special and get loaded.

## Other

- Every loading attempt writes one line to the game and server log (what is in hand, how much ammo fits, how much was discarded and why) - so that it can be investigated if loading fails again.
- Only the loading selftest was run.
