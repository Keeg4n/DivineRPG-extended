## Xaero minimap

- Add-on mobs (Carcinus, Lich King, Frost Colossus, Snow Glacon, Ancient Golem, Warrior King, Wind Lord, Ancient Dramcryx, Liopleurodon, the Great Cadillions, mini-bosses, the Watcher's eye, lair crabs, Wanderer, Charon, the training dummy, all summons) are no longer a question mark on the Xaero minimap but a colored dot, like Divine mobs. Xaero reads icon descriptions only for mobs from the global name list, and add-on mobs were not in it - now they are (only the /summon command tooltip also uses this list).
- Divine mobs (Wildfire and the rest) have been shown as a dot since 0.99.76: if they show a question mark on the minimap, this modpack has an add-on older than 0.99.76.
- The minimap selftest now also checks that Xaero will read the description of every mob.
- Hotfix: only the minimap test was run.
