## Fixed
- The game crashed on start in the RedServer Magic client ("Duplicate enchantment id! class morph.common.EnchantmentMorph ... Enchantment ID:120"): that client's Morph build registers an enchantment at ID 120, which 1.1.6 had given to Sweep. The addon's enchantments are now registered after all mods have loaded, so no other mod meets a taken ID, and their default IDs are 240-244.
- Configs from 1.1.6 with the old IDs 120-124 move to 240-244 by themselves, once (flag enchants.oldIdsMoved). Weapons enchanted in 1.1.6 lose these enchantments. If nothing in your pack uses 120-124 and you want them back, set the IDs back to 120-124 by hand: they then stay.
- The IDs must be the same on the server and the clients, as before: update both.
## Testing
- Hold a sword: `/enchant <player> 240` Sweep, `/enchant <player> 241 <1-3>` Agility, `/enchant <player> 242` Might, `/enchant <player> 243` Crown, `/enchant <player> 244` Spite.
- A book: `/give <player> enchanted_book 1 0 {StoredEnchantments:[{id:241s,lvl:3s}]}`.
## Other
- Selftests: the enchantments are registered after every mod's init and postInit; the old IDs move once, and IDs set by hand stay.
