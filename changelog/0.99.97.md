## Weather with one command

- `/dreblizzard start` now starts a blizzard in Iceika, a downpour in the Wildwood and a rockfall in Apalachia all at once (after a 30 second warning), and `/dreblizzard stop` cuts them off. Worlds where nobody is present are loaded automatically.
- An event that is already running is not restarted by a repeated start, and stop does not touch a lull.
- `/dreweather` for a single event remains.
